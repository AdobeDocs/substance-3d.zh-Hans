# OpenPBR常见问题解答

## OpenPBR模型

+++什么是OpenPBR？Painter支持哪个版本？

OpenPBR是由Academy Software Foundation托管的开放材料规范，定义了一个标准着色模型，旨在跨应用程序一致地工作。 [Painter的文档提供了有关使用OpenPBR](https://experienceleague.adobe.com/zh-hans/docs/substance-3d-painter/using/home)的更多信息。

+++

+++当应用程序声称“支持OpenPBR”时，它意味着什么？我如何知道特定应用程序支持它的程度？

由于没有正式的认证程序，所以索赔可能意味着不同的事情。 在实践中，实现方式会有所不同：某些实现方式涵盖整个规范，而其他实现方式仅涵盖一个子集，省略了薄膜、色散或某些次表面行为等功能。 另请注意，“MaterialX支持”和“OpenPBR支持”不是一回事；一个应用程序可能只支持其中一个，而没有完全实施另一个。

要了解特定应用程序实际支持哪些内容，可结合使用以下方法：查看发行说明（支持内容通常以增量方式添加）；加载ASWF的着色器平台，并快速与参考渲染进行对比，以找出表面差距；或者，对于拥有大量管道投资的工作室，请直接向供应商咨询所支持的功能及其路线图。

+++

+++OpenPBR是否能保证在不同应用程序和渲染器之间获得相同的结果？

不完全是，这是有意设计的。 OpenPBR定义共享材质模型，但最终外观还通过光照、渲染算法、色彩管理以及每个实现与规范的符合程度来决定。

在实践中，最大程度地实现保证意味着：通过集成MaterialX的USD进行导出；使用ASWF的OpenPBR着色器游乐场而不是在制作结束时提前验证往返操作；确认您的供应商对您使用的任何高级功能的支持级别；以及预先商定在共享材料中将使用哪些功能，而不使用哪些功能。 应该主动验证便携性，而不是假定便携性。

+++

+++是否有OpenPBR无法准确表示的材料？

可以。 OpenPBR是参数模型。 粗糙度、金属量和IOR等参数涵盖了绝大多数生产用例，但不能复制X-Rite AxF等测量材料格式的精度，这些格式可从物理样本中捕获实际光学数据。 对于一般的生产工作OpenPBR非常合适；对于需要精确样本匹配的应用，测量格式可能更合适。

汽车绘画就是一个有用的插图。 在OpenPBR中创造汽车绘画是可能的，但有一些需要注意的问题。 OpenPBR不包括专门的汽车绘画着色器，因此对于某些汽车工业用途可能不够。 此外，这完全取决于汽车绘画的类型 — 一些汽车绘画的房产永远不在任何特定着色器的范畴。 但考虑到这些因素，汽车绘画自然地映射到OpenPBR的分层建筑上。

+++

## 设置和转换

+++我是否需要学习OpenUSD或MaterialX才能使用OpenPBR？

不行。 对于大多数艺术家来说，OpenPBR只是他们已使用的工具中内置的材质模型。 Substance 3D Painter、Maya 2025.3和3ds Max 2026都使用OpenPBR作为默认材料；使用它只是意味着使用标准着色器。 只有当材料需要在应用程序之间移动时，USD和MaterialX才有意义。 对于单个应用程序的工作流程，本机支持就足够了；对于多DCC管道，USD和MaterialX提供了交换基础架构，但是主要位于场景之后。

话虽如此，共享材料库的最强大交换途径是通过USD与MaterialX集成，后者为材料描述提供了一个标准、渲染器不可知的容器。 将材料导出为独立资源（无关联模型，可在共享库中使用）的工作流程仍在开发中，尚未在所有地方都得到完全支持。 在提交依赖于此功能的库体系结构之前，对照当前功能验证您的特定管道。

+++

+++如何在Substance 3D Painter中创建新的OpenPBR项目？

默认情况下，不使用模板创建的项目使用着色器。 现在，“OpenPBR”着色器是新项目窗口中的第一个选项，它取代了ASM。 专用模板也可用于特定的工作流程（各向异性、外套、模糊、次表面散射），而导入包含OpenPBR材料的USD文件将自动配置项目。 Substance 3D Painter附带的示例项目也进行了更新，以使用OpenPBR工作流程，您可以从熟悉工作流程的实际操作开始着手。

+++

+++能否将现有Adobe Standard Material(ASM)项目转换为OpenPBR？

没有自动转换。 现有ASM项目在打开时会保留其当前的着色器，ASM模板仍可用于新项目。

要手动迁移到OpenPBR，请在着色器设置窗口中选择OpenPBR着色器，然后通过“纹理集设置”>“添加或删除频道”添加相关OpenPBR频道。 完成此操作后，查看现有图层，以确保其内容面向预期的通道。

+++

+++是否需要为OpenPBR更新我的自定义着色器？

否 — 现有的自定义着色器将继续工作，因为相关的着色器库已弃用而不是已删除。 但是，建议迁移到新的着色器库；它们更清晰，更易于使用。 有关详细信息，请参阅“帮助”菜单中的着色器 API更改日志。

+++

## 应用程序内使用

+++由于OpenPBR中提供了如此多的参数，我应该将注意力集中在哪里呢？

从简单开始。 对于大多数不透明表面，Base color、Specular粗糙度和金属度占材料之间可见差异的大部分。 如果精确的反射率很重要，请添加IOR；如果Specular具有掠角色调，请优化材料颜色。 只有在您具有明确、参考驱动的原因时，才能启用传输、亚表面、涂层、模糊、薄膜和色散，因为每个额外的通道都会增加复杂性和潜在的渲染成本。 隐藏或折叠未使用的参数组可让您的工作区保持聚焦，并降低出现意外效果的风险。

+++

+++我有一个粗糙度图 — 我应该将它插入基本Diffuse粗糙度还是Specular粗糙度？

粗糙度 — 用于控制反射锐度，直接等同于其他PBR工作流程中的粗糙度输入。 基本粗糙度是一个单独的专用参数，仅影响漫射散射；对于大多数工作流程，它可以保持默认状态。

+++

+++为什么使用次表面散射时更改Base color没有效果？

有一个“优先级层次结构”，它确定每个参数对材料的最终外观的影响程度。 喜欢这样：

* 金属性是第一位的：当金属性=1时，次表面和传动部件被关闭。
* 传递重量接下来的：如果传递重量=1，则不存在次表面。
* 下面的“重量”紧随其后。
* Base color排在最后：仅当上述各项均不设置为1时，基础扩散才起作用。

因此，在上述示例中，如果“子表面重量”设置为1（其最大值），则它控制所有外观。 更改Base color值没有效果，因为“基本”Diffuse基本上没有任何作用。 相反，如果“金属度”设置为其最大值1，则更改“传输重量”、“地下重量”和“Base color”的值将不会对材料的最终外观产生任何影响。 透射、次表面和Diffuse都是介电（非金属），因此将“金属度”设置为1可消除任何非金属贡献。

+++

+++为什么传播会出现意外行为？ 例如，当我启用我的网格时，它为什么看起来很暗？

最常见的错误是传输深度设置过低。 此参数定义在“透射颜色”达到完全饱和之前，光线的传输距离；在较低的值下，即使是细的几何形状也会显得暗而密集。 增加它以匹配对象的大致物理比例。 如果材料看起来过于清晰，请同时调整“Transmission Color”（传输颜色）和“Color”(深度)，找到适当的平衡点

散布可能会增加更多的复杂性。 透射色并不是一种简单的色调 — 它的效果取决于光线在物体中传播多远，而物体由透射色深度控制。 与此同时，“散点颜色”可控制单独的旅程光线 — 在材料内部来回反射，而不是直接穿过。 由于散射是有方向性的，因此结果也会随光源的位置而变化。 调整其中一个而不考虑另一个是常见的意外结果来源。

+++

+++我已启用薄膜，但看不到任何效果。 我错过了什么？

首先检查Thickness值。 与直觉相反，较细的值会产生更明显的虹影 — 大多数效果出现在0到1微米之间。 如果效果仍然不明显，请调整IOR，这会改变干涉的强度和颜色。 还要确认“薄膜重量”大于0。
