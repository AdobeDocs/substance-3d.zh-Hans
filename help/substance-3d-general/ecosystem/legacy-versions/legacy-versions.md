# 旧版本

旧版本的Substance 3D应用程序与过渡到激活Adobe帐户之前已有的旧版许可证密钥文件激活系统兼容。 这些版本与通过Adobe帐户或Steam帐户购买的许可证不兼容。

要下载Substance 3D Painter和Designer的旧版本，请访问以下地址：\
<https://www.substance3d.com/legacy-builds/>
