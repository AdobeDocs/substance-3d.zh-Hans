# 一般系统要求

## 硬件要求

+++Windows

|  | 最小 | 推荐 | 最佳 |
| --- | --- | --- | --- |
| <b>操作系统</b> | Windows 11（64位）23H2版 | Windows 11（64位）24H1版 | Windows 11（64位）24H2版 |
| <b>CPU</b> | Intel Core i5 AMD Ryzen 5 | Intel Core i7 AMD Ryzen 7 | Intel Core i9 AMD Ryzen 9 |
| <b>GPU</b> | NVIDIA GeForce RTX 2060 Super NVIDIA Quadro RTX 4000 AMD Radeon RX 5700 XT AMD Radeon Pro W5700 | NVIDIA GeForce RTX 3080 NVIDIA Quadro RTX A4000 AMD Radeon RX 6800 XT AMD Radeon Pro W7700 | NVIDIA GeForce RTX 4090 NVIDIA Quadro RTX 5000 Ada代AMD Radeon RX 7900 XTX AMD Radeon Pro W7800 |
| <b>VRAM</b> | 8 GB | 16 GB | 24 GB |
| <b>RAM</b> | 16 GB | 32 GB | 64 GB |
| <b>存储空间</b> | 具有30 GB可用空间的固态硬盘 | 具有50 GB可用空间的固态硬盘 | 具有70 GB可用空间的固态硬盘 |

+++Linux

|  | 最小 | 推荐 | 最佳 |
| --- | --- | --- | --- |
| <b>操作系统</b> | <b>企业ETLA</b> RHEL 8.6或更高版本或RHEL 9.2或更高版本<b>Steam</b> Ubuntu 22.04.1 LTS | <b>企业ETLA</b> RHEL 8.6或更高版本，或者RHEL 9.4或更高版本<b>Steam</b> Ubuntu 22.04.1 LTS或更高版本 | <b>企业ETLA</b> RHEL 8.6或更高版本，或者RHEL 9.4或更高版本<b>Steam</b> Ubuntu 22.04.1 LTS或更高版本 |


<b>Red Hat Enterprise Linux (RHEL) 9.x</b>：我们的应用程序所需的xcb-util-cursor程序包已于2024年5月10日从EPEL 9存储库中删除。 自此日期起，默认RHEL 9存储库支持该包，与RHEL 9.4的发行版一致。 在2024年5月10日之后，使用9.4之前版本的RHEL的客户将无法再从EPEL 9存储库中获取xcb-util-cursor包。

有关此包在默认RHEL 9存储库中的可用性的详细信息，请参阅： [Red Hat Enterprise Linux 9 — 包清单 — AppStream存储库](https://access.redhat.com/documentation/en-us/red_hat_enterprise_linux/9/html-single/package_manifest/index#AppStream-repository)

有关此更改的详细信息，请参阅： [Red Hat Bugzilla - Bug 2238273](https://bugzilla.redhat.com/show_bug.cgi?id=2238273) ， [Red Hat Bugzilla - Bug 2212302](https://bugzilla.redhat.com/show_bug.cgi?id=2212302)

## 其他说明

### 不支持的配置

* 不支持具有eGPU和用户安装的GPU的Apple计算机配置。
* 不支持Windows虚拟机。
* 不支持Windows Server操作系统。
