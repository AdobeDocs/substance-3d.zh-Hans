# 常见问题解答

+++什么是新的ADA门户？我可以使用它做些什么？


ADA门户可作为一个中央位置，供您管理许可证和认证。 使用ADA门户，您可以：



* 下载当前和以前的许可证。

下载当前和以前的许可证。

* 访问和下载数字认证。

访问和下载数字认证。

* 添加或删除与您的帐户关联的联系人。

添加或删除与您的帐户关联的联系人。

+++

+++如果没有收到订单确认电子邮件，该怎么办？


首先，检查垃圾邮件文件夹，确保邮件不会最后寄到那里。 如果您仍然找不到电子邮件，请联系您的客户经理或CSM。



+++

+++如何安装软件的早期版本？
要浏览并下载软件的旧版本，请执行以下操作：

* 打开ADA的“下载”部分。

* 单击“其他版本”。

+++

+++如何添加或删除联系人？


要添加帐户，请执行以下操作：

* 从页面标题打开您的联系人。

* 单击“添加联系人”。

* 输入联系信息。

* 单击“保存”。





要删除联系人，请执行以下操作：

* 从页面标题打开您的联系人。

* 选中帐户名称旁边的复选标记。

* 单击页面右侧的“删除联系人”。



+++

+++我在登录门户时遇到问题。 我该怎么办？


如果您收到与错误电子邮件或密码相关的错误消息，请确保您使用的是与帐户关联的正确凭据。





如果您遇到其他类型的错误，请[联系我们的企业支持](https://helpx.adobe.com/cn/enterprise/using/support-for-enterprise.html)。



+++

+++如何查看以前的订单购买历史记录？
只能通过LWS门户访问采购订单历史记录。 访问LWS门户：

* 转到[Adobe许可网站](https://licensing.adobe.com/)。

* 登录您的LWS帐户。

* 单击“报告”。

* 选择查看购买历史记录。

* 输入您的Adobe订单号。

* 单击“搜索”。

[此处提供了有关LWS的更多信息](https://helpx.adobe.com/cn/x-productkb/policy-pricing/volume-licensing-site.html)。



+++

+++如果需要更多帮助，我可以联系谁？
如需进一步帮助，请联系我们的企业支持团队。 您的管理员需要[登录AdobeAdmin Console并打开支持案例](https://helpx.adobe.com/cn/enterprise/using/support-for-enterprise.html)。

如果您需要进一步的帮助，可以联系AdobeCSM。

+++

+++我无法使用ADA中的许可证密钥文件激活软件。
[此处提供了详细的激活说明](../../../ecosystem/for-linux/substance-for-linux.md)。 如果这些方法无法解决您的问题，请[联系企业支持团队](https://helpx.adobe.com/cn/enterprise/using/support-for-enterprise.html)。
