# 如何导出已烘焙贴图？

>[!WARNING]
>
> **问题**
> 
> 如何从网格中导出烘焙的纹理以在其他应用程序中使用？

>[!NOTE]
>
> **解决方案：Substance Designer**
> 
> 面包师的输出文件应位于网格链接到的Substance图表的旁边。 右键单击并选择“浏览”，在应用程序的“资源管理器”窗口中查看文件。

>[!NOTE]
>
> **解决方案：Substance Painter**
> 
> Baker的输出文件保存在项目文件(\*.spp)中。 要导出这些文件，可以执行以下操作：
> 
> * 使用&#x200B;**文件>导出纹理**&#x200B;对话框，然后选择导出预设“网格图”
> * 右键单击架子中的烘焙纹理，然后选择“导出”。

>[!NOTE]
>
> **解决方案：Substance自动化工具包**
> 
> 默认情况下，贴纸的输出文件保存在网格旁边。 可通过命令行中的特定参数更改输出文件夹。
