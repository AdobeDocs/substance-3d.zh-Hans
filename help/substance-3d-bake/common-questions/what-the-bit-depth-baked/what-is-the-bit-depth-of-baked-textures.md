# 烘焙纹理的位深度是什么？

>[!WARNING]
>
> **问题**
> 
> 烘焙纹理的位深度是什么？

>[!NOTE]
>
> **解决方案：Substance Designer**
> 
> 该位深度取决于用于保存纹理的目标文件格式。

>[!NOTE]
>
> **解决方案：Substance Painter**
> 
> Baker输出将生成为16位RGBA纹理。 然后，最终位深度取决于用于保存纹理的目标文件格式。 32位文件格式将转换16位输入信息，但不会获得更高的精度。

>[!NOTE]
>
> **解决方案：Substance自动化工具包**
> 
> 该位深度取决于用于保存纹理的目标文件格式。
