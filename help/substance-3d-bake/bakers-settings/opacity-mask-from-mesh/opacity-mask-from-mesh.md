# Opacity Mask from Mesh

来自Baker的不透明度蒙版计算纹理，缺失射线在此转换为灰度二进制图像。 此纹理通常用作不透明度贴图。

纹理属性定义为：

* 黑色值表示空白区域。
* 白色值表示凸形区域。

**适用于：**

* Painter
* Designer
* 自动化工具包

## 参数：

此Baker没有特定参数。
