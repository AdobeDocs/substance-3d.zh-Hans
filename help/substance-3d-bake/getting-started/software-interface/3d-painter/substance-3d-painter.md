# Substance 3D Painter

![](../../../assets/sp-baking-button-access.png)

可以通过[纹理集设置](https://experienceleague.adobe.com/zh-hans/docs/substance-3d-painter/using/interface/texture-set/texture-set-settings)访问烘焙窗口。 单击名为“**烘焙网格图**”的按钮以打开当前项目的烘焙窗口。

## 概述

![](../../../assets/sp-ui-overview.png){width="400px"}

烘烤窗分为三个主要部件。

### 面包列表

![](https://helpx-prod.scene7.com/is/image/HelpxProd/sp-baking-list?$png$&jpegSize=100&wid=150)

窗口左上方提供了多个按钮。

这些按钮旁边有一个复选框，如果选中该复选框，它将为烘焙过程启用此烘焙。 名称旁边带有图标的按钮指示那些需要高多边形网格的按钮。 如果现在有高多边形可用，此图标将显示警告。

| *按钮* | *描述* |
| --- | --- |
| **常用** | 将参数视图更改为[公用参数](../../../bakers-settings/common-parameters/common-parameters.md)。 |
| **正常** | 将参数视图更改为[正常参数](../../../bakers-settings/normal-map-from-mesh/normal-map-from-mesh.md)。 |
| **世界空间正常** | 将参数视图更改为[世界空间法线参数](../../../bakers-settings/world-space-normals/world-space-normals.md)。 |
| **ID** | 将参数视图更改为[颜色参数](../../../bakers-settings/color-map-from-mesh/color-map-from-mesh.md)。 |
| **环境遮蔽** | 将参数视图更改为[环境遮蔽参数](../../../bakers-settings/ambient-occlusion-from/ambient-occlusion-from-mesh.md)。 |
| **曲率** | 将参数视图更改为[曲率参数](../../../bakers-settings/curvature/curvature.md)。 |
| **位置** | 将参数视图更改为[位置参数](../../../bakers-settings/position/position.md)。 |
| **Thickness** | 将参数视图更改为[Thickness参数](../../../bakers-settings/thickness-map-from-mesh/thickness-map-from-mesh.md)。 |
| **Height** | 将参数视图更改为[Height参数](../../../bakers-settings/height-map-from-mesh/height-map-from-mesh.md)。 |
| **弯曲法线** | 将参数视图更改为[弯曲法线参数](../../../bakers-settings/bent-normals-from-mesh/bent-normals-from-mesh.md)。 |
| **不透明度** | 将参数视图更改为[不透明度参数](../../../bakers-settings/opacity-mask-from-mesh/opacity-mask-from-mesh.md)。 |

### 参数

![](../../../assets/sp-baking-params.png)

窗口的这一部分显示各种烘焙设置。 其内容可根据当前选定的烘焙或常用参数而更改。

要了解有关面包机设置的更多信息，请参阅[面包机设置](../../../bakers-settings/bakers-settings.md)。

### 帮助消息

![](../../../assets/sp-baking-help.png){width="500px"}

此部分窗口显示与设置相关的各种工具提示和帮助消息。 将鼠标移至某一设置上方可在此处阅读其工具提示。
