# 加载项0.9.3

**加载项版本0.9.3+**&#x200B;的发行说明

* 在加载项首选项中添加OCIO 2.0色彩空间标签。
* 将说明作为工具提示添加到参数/输出工厂。
* 添加报告功能（整体）（删除入侵性弹出窗口，代之以本机混合器消息）。
* 在加载项首选项中安装和更新时更新SRE版本标签。
* 修复物质中并不总是可用的输出大小和随机植入。

**首选项部分：已添加/已更新：**

* 从默认着色器下拉列表中将物理尺寸循环切换为可用预设。
* 用于物理尺寸默认投影混合的控件。
* 已更改支持链接以指向discord服务器。
* 修复了在插件首选项中显示正确的当前SRE版本的问题。
* 如果需要更新，则显示所有兼容的加载项版本。
* 当缺少SRE时，显示支持的版本数组，而不是第一个版本。

**Substance 3D面板部分：已添加/已更新：**

* 材料的物理尺寸显示在“图形参数”(Graph Parameters)下（以米为单位）。
* “循环/Eevee物理尺寸”可从着色器下拉列表中获得。
* 如果所有参数都是不可见的，请隐藏参数组。
