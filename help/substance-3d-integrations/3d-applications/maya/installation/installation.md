# 下载和安装

默认情况下，Maya增效工具中的Substance包含在Maya安装程序中。

您可以从[Adobe的Substance 3D for Maya页面](https://substance3d.adobe.com/plugins/substance-in-maya/)下载安装程序的较新版本。
