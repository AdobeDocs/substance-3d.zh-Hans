# 将工作流应用于地图

您可以使用&#x200B;**将工作流程应用于地图**，快速将来自Substance 3D Painter的导出纹理或任何绘画应用程序应用于Maya中的材质。

**工作流**&#x200B;选项允许您选择正在使用的渲染器，例如Arnold。

![](../../../assets/applymaps.png)

使用&#x200B;**选择多个映射**&#x200B;可根据左侧列出的命名惯例选择要应用的多个映射。 *例如，\_roughness将映射到粗糙度通道。*

通过单击文件夹按钮并选择纹理，可以添加单个地图。
