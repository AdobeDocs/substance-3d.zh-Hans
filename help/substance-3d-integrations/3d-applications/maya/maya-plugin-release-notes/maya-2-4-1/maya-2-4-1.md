# Maya 2.4.1

<b>已添加/已更新：</b>

* Maya插件现在默认使用GPU，可显着提高性能和渲染速度。

<b>已修复：</b>

* 更正了Maya增效工具的“关于Substance”菜单中的链接，以重定向到正确的发行说明页面，现在可正确指向https://helpx.adobe.com/substance-3d-integrations/3d-applications/maya/maya-plugin-release-notes.html。
* 解决了Maya增效工具中显示的分辨率值在重置素材后不会在UI中更新的问题，确保包括分辨率在内的所有值现在都正确重置为默认状态。

在Linux、macOS和Windows上为Maya 2020、2022和2023发布了Maya 2.4.1
