# Maya 0.9.11

**Maya 2.0更改：**\
**稳定性**：

* 来自图形的动态属性现在以本机方式创建，而不是通过属性编辑器代码创建
* 在初始化节点时可以批量创建Substance节点，无需UI输入
* 属性编辑器和属性编辑器明显更加稳定
* 内存性能显着提高，足以在GPU引擎上实现8k输出
* 设置/首选项现在保存为单独的配置文件，可以在Maya外部轻松编辑

**脚本**：

* 强脚本API，具有从获取输入、图形和输出信息到加载sbsar包、更改图形以及在预设管理器中执行任何预设操作的任何操作
* 旨在使用与公共脚本API相同的功能的UI代码

**Substance功能**：\
**预设支持：**

* 设计器中设置的嵌入预设将加载到预设管理器中
* 导入和导出sbsprs文件，包括多个预设
* 预设管理器
* 引擎V7支持
* 已使用即将与Designer 2019.1一起发布的新Substance引擎
* 数字输出在
* 图形/substance节点，该节点可以插入超阴影中的其他节点

**工作流系统：**

* 适用于Arnold、Renderman、VRay、Corona等的新工作流程
* Python中的自定义工作流程扩展
* 从超阴影中反转工作流程脚本，设置自定义工作流程一次并将其保存
* 对Substance Painter中的图像映射使用工作流程

**UI和UX改进：**

* 文件 — > import .sbsar创建substance节点
* 将sbsar文件从文件浏览器拖放到超阴影以创建substance 2节点
* 属性现在由Designer中设置的类别编排

**其他改进：**

* 图像输入现在适用于程序化的节点
* 现在可以为程序化的节点设置采样率，以便能够对程序化的图像输入进行向下或向上采样
* 输出节点现在显示以Substance Designer编码的输出信息
* Substance/图形节点现在可以显示图形信息（作者等）
* 图层覆盖支持，例如连接覆盖和属性覆盖
* 缓存到磁盘为任何HDR输出选择exr文件类型，这些输出具有16位、16位浮点或32位浮点输出
* 来自旧版插件的映像
* 使用新增效工具加载场景会将旧图形和输出节点转换为Substance 2节点
