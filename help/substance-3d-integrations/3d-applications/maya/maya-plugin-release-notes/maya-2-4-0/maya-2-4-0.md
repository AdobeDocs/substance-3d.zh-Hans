# Maya 2.4.0

<b>已添加/已更新：</b>

* 已在Maya增效工具中将Substance引擎升级到版本9，从而提升了性能和兼容性。

<b>已修复：</b>

* 修复了Maya 2023中的一个关键问题，此问题会导致应用程序崩溃，从而确保使用Substance引擎版本9或更早版本创建的sbsar文件创建网络，同时确保稳定地创建包含这些文件的网络。

在Linux、macOS和Windows上为Maya 2020、2022和2023发布了Maya 2.4.0
