# Maya 2.3

更改列表：

* 添加了启用物理尺寸的模式。 这会将三平面投影计算添加到节点网络中，并且可以打开和关闭
* 添加了新脚本命令、用于启用/禁用物理尺寸的substanceUtilityActivatePhysicalSize以及用于在修改后重置投影值的substanceUtilityResetPhysicalSize。
* 添加了substanceNodeGetPhysicalSize命令以获取图形的物理尺寸值。
* 添加了用于启用/禁用以及重置的新复选框和按钮。 在Substance图形的物理尺寸的属性编辑器中添加了显示。
* 添加了用于全局启用物理尺寸功能的设置
  * 如果启用了物理尺寸特征，则渲染器工作流支持创建这些投影节点
* 不再支持Maya 2017

1. 3已发布用于
1. Linux、macOS和Windows上的Maya 2018、2019、2020、2022和2023
1. macOS和Windows上的Maya LT 2018、2019和2020
