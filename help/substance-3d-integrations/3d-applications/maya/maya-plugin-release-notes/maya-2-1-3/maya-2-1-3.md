# Maya 2.1.3

2020年6月17日发布

今天，我们发布了增效工具的2.1.3版本。

2.1.3版：

* 现在，安装程序在Windows上已使用SHA-256签名
* 安装程序中的所有二进制文件现在都在Windows上签名
* substance\_link.dll和substance\_portal\_cli.dll现在具有Windows上的版本/描述信息
* 为Maya 2020中的标准表面添加了一个工作流程选项

此版本在Windows、Linux和Macos上为Maya 2017、2018、2019和2020发布。 它还在Windows和MacOS上为Maya LT 2018、2019和2020发布。
