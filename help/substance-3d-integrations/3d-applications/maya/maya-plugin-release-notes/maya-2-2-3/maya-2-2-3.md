# Maya 2.2.3

更改列表：

* 增加了对Arnold 7.1.0/MtoA 5.1.0的支持，适用于Maya 2019、2020和2022
* 添加了一个新的脚本命令“substanceNodeGetGraphMetadata”，以将Substance图形元数据作为脚本中的XML字符串获取
* 在脚本调用中查询越界图形不再是崩溃
* 现在，Arnold和MtoA插件安装在使用语义版本号之间的“ — ”分隔符的目录中
* 引擎资源设置现在已得到适当遵守，从而修复了忽略它们的回归问题。

1. 2.3已发布用于
1. Linux、macOS和Windows上的Maya 2017、2018、2019、2020、2022和2023
1. macOS和Windows上的Maya LT 2018、2019和2020
