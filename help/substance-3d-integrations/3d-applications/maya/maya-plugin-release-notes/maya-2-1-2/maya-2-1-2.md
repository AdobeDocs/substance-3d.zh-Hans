# Maya 2.1.2

2020年6月2日发布

今天，我们发布了增效工具的2.1.2版本。

它包含的唯一更改是：

* 修复了创建Stingray着色器网络时Maya LT中的错误。

该版本还与Maya 2020.2一起发布，并包含在Maya安装程序中。

它针对相同平台发布，即Maya 2017 - 2020和Maya LT 2018 - 2020
