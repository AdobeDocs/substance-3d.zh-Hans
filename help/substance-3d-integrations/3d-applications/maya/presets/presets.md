# 预设

在预设部分，您可以完全管理在Substancesbsar文件中找到的嵌入预设，也可以创建新预设。

![](../../../assets/presets-15.png)

要创建预设，请对Substance参数进行任何更改，然后单击“创建”按钮。

![](../../../assets/preset-save.gif)

要应用预设，请从菜单中选择预设，然后单击“应用”。 如果需要覆盖预设，可以从菜单中选择预设，然后单击“覆盖”按钮。 这将使用新设置更新预设。 您还可以导入和导出Substance预设文件(.sbsprs)。
