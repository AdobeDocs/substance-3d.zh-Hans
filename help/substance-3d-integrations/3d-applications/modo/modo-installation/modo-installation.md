# Modo安装

要安装插件，只需将LPK文件拖放到MODO中即可。 如果您尚未安装套件或MODO内容包，系统可能会显示一个对话框，要求您创建相应的文件夹。 安装套件后，您会在MODO UI的右上角看到“Substance”按钮。
