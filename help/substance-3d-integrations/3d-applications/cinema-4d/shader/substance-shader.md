# Substance着色器

Substance着色器是Substance资源和Cinema 4D素材之间的链接。

Substance着色器可在常规Cinema 4D材质编辑器选择菜单中找到，如下面的屏幕截图所示：

![](../../../assets/cinema-4d-6.png){width="500px"}

手动添加Substance着色器后，它将没有链接的Substance资源。 它看起来如下所示，渲染后，素材将与右侧的图像类似：

![](https://helpx-prod.scene7.com/is/image/HelpxProd/cinema-4d-7?$png$&jpegSize=300&wid=1506){width="500px"}

要访问Substance着色器的参数，可以单击左上角的小箭头或着色器的预览图像。

![](../../../assets/cinema-4d-8.png){width="500px"}

## 参数

Substance着色器有两个参数：

* **资源：**&#x200B;可在此处从Substance资源管理器中删除Substance资源以将其链接到着色器。 换句话说，它将Substance资源链接到Cinema 4D素材渠道。
* **通道：**&#x200B;选择链接Substance的输出通道。
