# 设置

## 要求

需要Cinema 4DR16或更高版本。 支持除Cinema 4DLite之外的所有产品版本。

可以使用[Substance Designer](https://www.allegorithmic.com/products/substance-designer)创建Substance文件。

## 安装

## Windows

1. 安装期间不应运行Cinema 4D。
1. 运行自安装包。
1. 选择/检查目标文件夹。 这应该是Cinema4D的安装文件夹，而不是plugins子文件夹。
1. 单击“安装”。
1. 成功安装后，您可以选择启动Cinema 4D。

## MAC OS X

1. 安装期间不应运行Cinema 4D。
1. 将cld文件放入Cinema 4D增效工具文件夹中。
1. 照常开始Cinema 4D。
