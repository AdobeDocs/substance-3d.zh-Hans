# Cinema 4D

>[!NOTE]
>
> 该Substance增效工具已本机安装在R18及更高版本的Cinema 4D中，由Maxon开发。

Substance增效工具基本上由两个组件组成： **Substance文件**&#x200B;和&#x200B;**Substance着色器**。

* Substance资源表示Cinema 4D中的实际Substance。 它们在Substance资产管理器中进行管理。
* Substance着色器将Substance资源的输出通道与Cinema 4D素材通道相连接。
