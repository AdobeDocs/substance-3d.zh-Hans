# 使用Substance插件

Substance增效工具位于“Cinema 4D增效工具”菜单中。

![](../../../assets/cinema-4d-1.png){width="500px"}

## 加载资源……

使用此选项可将Substance资源加载到场景中。 只能加载Substance存档(.sbsar)。 如果尚未显示SubstanceAsset Manager，则成功导入Substance后将自动打开它。 此命令也可在Substance资源管理器中找到。

导入时，系统可能会询问您是否应该将Substance复制到项目文件夹中。

![](../../../assets/cinema-4d-2.png){width="500px"}

* 如果回答“否”，则Substance的绝对路径将存储在场景中。
* 如果回答“是”，则Substance将被复制到项目的tex子文件夹中，并且在您的场景中，它仅会被文件名引用。

每次导入时（例如，从资源管理器或Finder中拖放多个Substance时），此提示仅出现一次。
