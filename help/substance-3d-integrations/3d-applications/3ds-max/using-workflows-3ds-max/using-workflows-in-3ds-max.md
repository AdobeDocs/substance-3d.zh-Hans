# 在3ds Max中使用工作流

3ds Max增效工具中的Substance包含用于自动创建着色器网络以支持渲染器的工作流程。 可在“Substance”菜单中找到渲染工作流程。

![](../../../assets/workflows-3.png)

要使用工作流，请在材料编辑器中选择“Substance”节点，然后从“Substance”菜单中选择工作流。

![](../../../assets/max-workflow.gif)
