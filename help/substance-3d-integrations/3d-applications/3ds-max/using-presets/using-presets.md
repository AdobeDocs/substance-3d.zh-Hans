# 使用预设

Substance文件可以包含嵌入的预设文件。 如果Substance嵌入了预设文件，它将显示在“Substance预设”窗口中。 您还可以根据为“Substance参数”选择的设置创建自己的预设。

![](../../../assets/max9.png)

1. “创建预设”将根据您在3ds Max中为Substance设置的参数设置创建新的预设。
1. 导入预设将导入预设文件(.sbsprs)。
1. 存储预设将存储当前所选预设的参数值。
1. 导出所选预设将预设导出到预设文件(.sbsprs)。
1. 移除所有预设将移除预设列表中的预设。
1. 移除选定预设将仅移除选定预设。
