# 3ds Max 2.4.0

发布日期：2020年8月10日

已添加：

* 新材料示例

已修复：

* 参数块冲突

已知问题：

* 在Substance对象上加载具有关键帧的旧场景并打开曲线编辑器，但不保存场景并重新打开它，3dsMax将崩溃。 解决方法是将场景保存到文件的新版本，然后重新打开

此版本针对3ds Max 2019、2020和2021发行
