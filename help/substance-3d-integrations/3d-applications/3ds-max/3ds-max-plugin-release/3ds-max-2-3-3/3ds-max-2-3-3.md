# 3ds Max 2.3.3

2020年6月3日发布

今天，我们发布了增效工具的2.3.3版本，它是2.3.2之上的错误修复版本。

2.3.3版：

* 增效工具文件已从SubstanceMax.dlt重命名为substancemax.dlt
* 已将版本和描述信息添加到substance\_link.dll
* 修复了Redshift检查版本的问题，现在应可与Redshift 3配合使用
* 修正了将sbsar加载到Substance节点后撤消/重做时发生崩溃的问题
* 修正了使用设置对话框时回归不起作用的问题
* 修正了加载包含非拉丁字符的sbsar文件时崩溃的问题

我们的发布渠道也得到了彻底重做，因此，与我们过去做过的大型、超远距离的发布相比，您应该能够期待更频繁的发布。

此版本针对3ds Max 2018、2019、2020和2021发行。
