# 3ds Max 2.2.0

发行日期：2019年6月4日

* 增加了对3ds Max 2020的支持
* 更新到Substance 引擎V7，添加了对来自Designer 2019.1的值处理器的支持
* 现在，增效工具会加载与其自身相关的引擎
* 通过Microsoft工具更改为MSI格式、正确执行静默安装/卸载
* 安装程序和文件现在已正确签名
* 安装程序不再修改原始增效工具中的任何文件
* 修复了3ds Max 2019（和2020）中无法加载菜单的问题
* 添加了对ART渲染器的本机支持
* 修复了没有光泽度输出时Corona工作流程脚本的问题
* 工作流脚本现在作为纯.ms文件分发，并且可以检查
* 较小的外观改变和稳定性改进
