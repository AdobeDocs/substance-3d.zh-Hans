# 胡迪尼

>[!NOTE]
>
> Houdini中的Substance由SideFX Labs开发。

使用[Houdini的Substance插件](https://www.sidefx.com/tutorials/sidefx-labs-substance-plugin/)，可在COP中将Substance存档文件(SBAR)加载到Houdini中。 这使您能够将Substance节点链接在一起，将Substance图表的输出提供给Houdini的所有部分（地形、材质、几何）和许多其他工作流。 该增效工具由SideFX Labs团队维护。

## 安装说明

对于Houdini 17.5，可通过GameDevelopment工具集分发该插件\
[GameDevelopment工具集安装说明](https://www.sidefx.com/tutorials/game-dev-toolset-installation/)

对于Houdini 18.0，该插件随SideFX Labs一起分发。\
[SideFX实验室安装说明](https://www.sidefx.com/tutorials/sidefx-labs-installation/)
