# Substance输入图像 — UE4

可以使用输入创建Substance，您可以在其中提供图像以在素材中处理。 这允许您创建模块化素材，这些素材可将烘焙网格数据或图案作为输入来更改素材或将素材与资源匹配。 要使用纹理作为Substance输入，必须将其作为Substance输入纹理导入UE4。

1. 将纹理导入内容浏览器。 对于“格式”，选择“Substance图像输入”(jpg、tga、jpeg)。
1. 此纹理现在可与Substance输入一起使用。
