# 非实际插件4.26.0.2

已添加：

* Substance 引擎版本8.0.3支持
* Substance Source操作现在可访问Substance启动器中的“源”选项卡，从而允许将资源直接发送到UE4 （[详细信息](../../../../../game-engines/unreal-engine/unreal-engine-4/source-in-ue4/source-in-ue4.md)）
* 在升级项目版本时减少一次处理的Substance材料数量

已修复：

* 关闭安装了UE4Substance增效工具的编辑器时，UE4在Mac上崩溃
* 更改Substance 图形实例中的文本参数会导致冻结并最终崩溃
