# 输入图像- UE5

创建Substance时可以提供图像以在材料中处理。 这允许您创建模块化材料，这些模块可以将烘焙的网格数据或模式作为输入来更改或确认资源的材料。

* 可以将UTexture2D与Substance输入一起使用。
