# Substance输入图像 — UE5

创建Substance时可以提供图像，以供在素材中进行处理。 这允许您创建模块化素材，这些素材可将烘焙网格数据或图案作为输入来更改或确认素材到资源。

* 可以将UTexture2D与Substance输入一起使用。
