# Unreal plugin 5.0.1

更新/添加：

* 支持Unreal Engine 5.0.0及更高版本
* Unreal Engine 5增效工具文档
* 支持新的三平面材料模板
* 支持新的“物理尺寸”功能
* *改版* Substance标准模板和Substance折射模板
* 修改世界空间的XYZ值的能力
* Python脚本
* 使用substance输出中的值自动设置物理大小素材节点

已删除：

* UE 5增效工具中的float4参数

已修复：

* 打包的UE5项目在通过蓝图调整材质参数时崩溃
* 未选中Substance 图形实例的输出时，插件会关闭参数窗口
* 修正了导致参数更改延迟的偶尔渲染延迟
