# Unreal plugin 5.3.2

2023年12月4日发布

<b>已修复</b>

* 解决了用于虚实引擎的Mac 5.3上的Substance增效工具无法运行的兼容性问题。
* 修复了在“虚构引擎”的Substance增效工具中取消选择材料声道不再导致崩溃的问题
* 解决了增效工具中的“stone-arc.sbars”材料在“输入”部分下仅显示“输出大小”选项，而不是显示完整范围的可修改材料属性的问题
* 修复了Substance增效工具中的颜色偏移问题，导入的材料显示错误的红移法线和脱色基数图。
* 修复了Substance增效工具中的崩溃问题：在。sbsar 文件上使用“重新导入”会导致编辑器崩溃。
* 改进了Substance增效工具中的输入验证，以防止关键材料属性字段中的条目超出范围和无效。”
* 修复了在Substance增效工具中创建第二个图形实例会删除所有以前加载的预设的错误。”
* 修复了重新导入Substance工厂实例时会删除所有现有预设的问题。
