# 在Unity中下载Substance 3D插件

## Asset Store

Substance 3D for Unity在[Unity Asset Store](https://assetstore.unity.com/packages/tools/utilities/substance-3d-for-unity-beta-213208)中提供。 随后该插件即会添加到项目中的Assets文件夹中。

## 包管理器

通过Asset Store添加并下载插件后，即可在&#x200B;**我的资源**&#x200B;下使用包管理器（Unity 2020.3.27x及更高版本）访问该插件。

![](https://helpx-prod.scene7.com/is/image/HelpxProd/screen-shot-2022-03-29-at-10-45-20-am?$png$&jpegSize=300&wid=1920)

### 包管理器缓存

Asset Store缓存会影响您在“包管理器”/“我的资源”中看到的可用版本。 如果您没有获得最新版本，则可能需要删除Asset Store缓存。\
