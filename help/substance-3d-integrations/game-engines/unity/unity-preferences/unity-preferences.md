# Unity首选项

通过“Substance 3D”首选项窗口，您可以为增效工具设置用户定义的选项。

**生成所有图形输出** — 将始终为每个图形生成所有图形输出。

**纹理分辨率** — 每个图形生成的纹理的默认分辨率

**CPU最大分辨率** — 使用CPU引擎时支持的最大纹理分辨率。

**Substance 3D资源** — 链接到Substance 3D Assets页面。

**Substance3d社区资源** — 指向Substance 3D社区资源页面的链接。

**关于** — 显示插件版本信息。
