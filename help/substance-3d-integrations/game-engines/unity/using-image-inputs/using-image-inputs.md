# 使用图像输入

要在Substance的输入参数中使用图像，请执行以下操作：

1. 在Substance 图形的检查器窗口中，您可以选择项目中的纹理以分配给图像输入。

   ![](../../../assets/imageinput-inspector.png)
1. 请注意，选择纹理将导致选中纹理“已启用读取/写入”字段，因为这是将纹理数据读入Substance材料所必需的

   ![](../../../assets/imageinput-texture.png)
