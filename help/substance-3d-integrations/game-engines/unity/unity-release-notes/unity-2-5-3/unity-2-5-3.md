# Unity 2.5.3

2020年11月4日发布

已修复：

* 更改Specular映射的打包时崩溃
* Specular映射在标准3d项目中的Alpha 通道中不是打包Smoothness
* 删除“资源库”文件夹后重新启动HDRP/HRP项目时崩溃
* 重复的材料缺少分配的着色器和材料属性
* 场景和预设文件中的行尾字符更改。

已知问题：

* 无法从Unity中的源中一致地下载资源。 解决方法是从[Substance Source网站](https://source.substance3d.com/)下载并手动导入资源。
