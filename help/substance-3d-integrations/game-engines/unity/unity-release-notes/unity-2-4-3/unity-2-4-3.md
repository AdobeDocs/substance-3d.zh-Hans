# Unity 2.4.3

发布日期：2019年12月

错误修复：

* 修复：法线图反转
* 修复：检查器内的起始垂直位置问题
* 修复：“检查器图形”的“生成的纹理”部分中的滚动条处理。 已清除调试文本
* 已修复：平台分辨率悬停文本上出现“PC、Max和Linux”拼写错误
* 修复：更改“平台分辨率”设置并单击“材质”导航按钮时出错
* 修复：HDRP打包未正确处理AO。 蒙版映射绿色通道为黑色
* 修复：（回归，仅限Mac）没有有效纹理映射的数字输出/Substance导致Unity崩溃。
* 修复：更改参数和单击Substance的其他实例时崩溃。
* 修复：单击主Substance对象，然后单击Substance图形时出现GUI错误（仅限2019.2及更高版本）
* 修复：导入sbsar文件时出现Unity 2019.3错误
* 修复：除非脚本中有渲染调用，否则Duplicate()函数不会完全渲染Substance
