# Unity发行说明

从Unity 3.0.0版本开始，我们目前支持适用于Unity的Substance 3D增效工具。 早期版本的Substance 3D增效工具适用于旧版本的Unity，即将弃用。

**从2.2.0到2.6.0的Unity版本即将弃用。**
