# Unity 2.5.4

2020年12月9日发布

已修复：

* 当Unity项目包含材料时，无法生成与位码兼容的iOS应用程序

已知问题：

* 无法从Unity中的源中一致地下载资源。 解决方法是从[Substance Source网站](https://source.substance3d.com/)下载并手动导入资源。
* 当前不支持Unity 2020.2及更高版本
