# 在项目之间共享sbsar文件

可以在项目和计算机之间共享.sbsar文件，同时使用.sbsprs文件保持相同的参数调整。

将原始项目中的素材修改为将共享的设置后，导航到“检查器”面板中的预设设置。 在预设设置中，创建一个新预设并将其命名。 这种新命名的预设将出现在这种素材的预设列表中。 完成此操作后，导出预设以将其保存在本地。

在其他项目或计算机中使用.sbsar时，还应包含导出的预设文件。 将sbsar导入Unity项目后，导航到预设设置并选择导入选项。 选择上一个步骤中的预设文件并导入。 应将包含上一个项目设置的预设添加到预设列表中。

对所有共享素材重复此操作。
