# 游戏引擎

您可以通过Substance增效工具在大多数主要引擎中导入Substance文件(.sbsar)。

* <b>Unity</b>在2017版周期内本机集成了Substance增效工具。 对于Unity 2018和更高版本，可在[Unity Asset Store](https://assetstore.unity.com/packages/tools/utilities/substance-in-unity-110555)中找到Substance增效工具。
* 可在[Unreal Marketplace](https://accounts.unrealengine.com/logout?redirectUrl=https%3A%2F%2Fwww.unrealengine.com%2Fmarketplace%2Fsubstance-plugin)上找到<b>Unreal Engine</b>插件。
* <b>Lumberyard</b>增效工具已本机集成。
* <b>CRYENGINE</b>增效工具已本机集成并由Crytek维护。 有关详细信息，请访问[SubstanceCRYENGINE文档](https://docs.cryengine.com/pages/viewpage.action?pageId=44968527)
