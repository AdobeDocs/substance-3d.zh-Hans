# Lumberyard

![](../../assets/lumber.jpg){width="800px"}

该Substance 引擎在适用于Windows、Mac、PS4和Xbox One的Lumberyard打包内部版本中工作。 该Substance增效工具还与Lumberyard Editor的所有版本（Windows和Mac）兼容。

该增效工具已本机集成到引擎中。
